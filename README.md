# Grand Prix Manager

Jeu de course et de gestion d'écurie de monoplaces, jouable sur téléphone (univers fictif).

**Jouer :** https://pierremrt528.github.io/jeu-f1/

Sur téléphone : ouvre le lien, puis « Ajouter à l'écran d'accueil » pour l'installer comme une appli.

Commandes : ◀ ▶ pour tourner, GAZ et FREIN à droite (flèches du clavier sur ordinateur).
