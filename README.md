# Grand Prix Manager

Jeu de course de monoplaces en 3D et de gestion d'écurie, jouable sur téléphone (univers fictif).

**Jouer :** https://pierremrt528.github.io/jeu-f1/

Sur téléphone : ouvre le lien, tourne l'écran en paysage, puis « Ajouter à l'écran d'accueil » pour l'installer comme une appli.

Commandes : ◀ ▶ pour tourner (ou inclinaison du téléphone, à activer dans le menu), GAZ et FREIN à droite, bouton 🎥 pour passer de la vue arrière à la vue cockpit.
Sur ordinateur : flèches, C = caméra, P = pause.

Moteur 3D : [three.js](https://threejs.org) (licence MIT, copie dans `lib/`).
